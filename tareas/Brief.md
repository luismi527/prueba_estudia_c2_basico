# Brief para el tema Suicidios.
1. **Usuario:** Lo puede usar el gobierno, organizaciones no gubernamentales, periodistas, etc.
2. **Fuente:** master.csv, Boletines estadísticos mensuales de medicina forense.
3. **Destino:** Una tabla de suicidios por departamento y año, o también una especia de tablero que se actualiza a medida que se van añadiendo los datos para observar el comportamiento de manera mensual.
4. **Tres KPI:** Suicidios por día, Grupo etario que más se suicidad.
5. **Frecuencia:** Anual.
6. **Calidad mínima:** Sin datos de suicidios duplicados.
7. **Terminó bien:** Corre dos veces seguidas con el mismo resultado, y sus dos KÍ coinciden con una cuenta manual.
8. **Fuera:** Políticas públicas del país.
